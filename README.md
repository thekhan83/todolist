# TaskPulse - Modern To-Do & Productivity Analytics 🚀

모던하고 직관적인 인터페이스의 할 일 관리 및 생산성 분석 웹 애플리케이션입니다.

![TaskPulse](https://img.shields.io/badge/Status-Active-brightgreen)
![Tech](https://img.shields.io/badge/Tech-Vite%20%7C%20Vanilla%20JS%20%7C%20CSS-blue)

## ✨ 주요 기능 (Key Features)

- **할 일 관리 (Task Management)**: 할 일 추가, 수정, 삭제, 완료 체크 및 중요도 설정
- **카테고리 & 태그 분류**: 다양한 카테고리와 태그로 체계적인 일정 관리
- **생산성 통계 (Analytics)**: 완료율 및 일정 달성 추이를 시각화한 대시보드
- **다크/라이트 모드 지원**: 편안한 테마 전환
- **반응형 디자인 (Responsive UI)**: 모바일 및 데스크톱 환경 지원
- **데이터 로컬 저장**: 브라우저 로컬 스토리지를 통한 영구 보관

## 🛠 기술 스택 (Tech Stack)

- **Frontend**: Vanilla JavaScript (ES6+), HTML5, Vanilla CSS
- **Bundler & Dev Server**: [Vite](https://vitejs.dev/)
- **Libraries**:
  - [Lucide Icons](https://lucide.dev/)
  - [Chart.js](https://www.chartjs.org/)
  - [canvas-confetti](https://github.com/catdad/canvas-confetti)

## 🚀 시작하기 (Getting Started)

### 설치 (Installation)

```bash
git clone https://github.com/thekhan83/todolist.git
cd todolist
npm install
```

### 실행 (Development)

```bash
npm run dev
```

### 빌드 (Production Build)

```bash
npm run build
```
